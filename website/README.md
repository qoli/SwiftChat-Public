# SwiftChat website

Buildless static website in `dist/`, deployed by `.github/workflows/pages.yml` to
GitHub Pages and `swiftchat.ronniewong.cc`. Preview with:

```sh
python3 -m http.server 18766 --directory website/dist
```

`dist/updates/alpha.xml` and `dist/releases/alpha.json` are generated by the private
release pipeline after signing, notarization and GitHub asset verification.
Do not hand-edit release metadata or replace a published archive.

The first-release placeholder has an empty valid RSS feed and no alpha JSON.
Downloads are enabled only when verified release metadata exists.

## Screenshot provenance

Screenshots were captured from the actual macOS SwiftChat build with Sparkle
integration on September 24, 2026. `conversation.png` uses a newly created
synthetic Kyoto itinerary conversation; `context.png` previews a purpose-made
TextEdit note; no personal chat history is shown. `icon.png` is exported from the
compiled app icon. Screenshots and branding are not covered by the adapter MIT
license. `browser.png` shows the public SwiftChat homepage inside the native Browser.

The landing page's `chat-window.png` and `accounts-window.png` are the original
transparent product images supplied in the SwiftChat Figma file on October 18,
2026 (file `XLP9OJJoBUdUvCOXpUZMlV`, nodes `1:68` and `1:71`). They are stored
locally and composed with CSS; the site does not depend on temporary Figma URLs.

The transparent header mark uses the original `Message`, `Message lines`, and
`Reply` SVG assets from the same Figma file (nodes `1:49`, `1:51`, and `1:54`,
inside `1:48`). `brand-message.svg`, `brand-lines.svg`, and `brand-reply.svg` are
stored without modification and composed at the original layer offsets in an
SVG viewport. The mark has no rectangular app-icon background.
